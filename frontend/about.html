PROJECT GUIDE

About this system

A learning-focused computer vision pipeline for historical chart images.

Objective

MarketLens demonstrates an end-to-end workflow: validate an uploaded chart, preprocess it consistently, classify it with a trained convolutional neural network (CNN), and save the result for later outcome comparison.

Technology

Python, Flask, SQLAlchemy, PostgreSQL, OpenCV, Pillow, PyTorch, Torchvision, scikit-learn, HTML, CSS, and vanilla JavaScript.

Model overview

The CNN accepts a 128 × 128 RGB image scaled to values from 0 to 1. It has convolution, batch normalization, ReLU, pooling, dropout, and fully connected layers. The model returns two classes: Bearish and Bullish. If the highest softmax score is below a configurable threshold, the user-facing classification is Uncertain.

Dataset and labels

Training images should be generated from permitted historical OHLCV data. Each image shows only bars up to its prediction timestamp. Its label is the next candle's close versus open; exact dojis are excluded. Split the chronological raw bars before generating windows, and reserve the latest test period for one final evaluation. The repository does not contain market data or a pretrained checkpoint.

Understanding the score

Softmax confidence describes the model's relative score among its two trained classes. It is not necessarily calibrated: for example, a 0.8 score does not prove an 80% chance of correctness. Calibration needs separate evaluation data. Accuracy, precision, recall, and F1 from historical unseen test data describe only that test period and may not generalize to future markets.

Limitations and risk

Chart formatting, zoom, colors, indicators, instrument, and timeframe may shift the image distribution. Financial series are non-stationary and a chart-only prediction omits important context such as costs, liquidity, and news. A classifier result does not establish a profitable strategy.

Not financial advice. This project is for education and experimentation. Do not use its output as the sole basis for financial decisions.
